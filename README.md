# P3D

เว็บประเมินราคาพิมพ์ 3 มิติแบบ FDM ออกแบบสำหรับ P3D เริ่มประเมินได้ทันทีโดยไม่ต้องเข้าสู่ระบบ

## เปิดเว็บในเครื่อง

ต้องใช้ Node.js 22.13 ขึ้นไป เปิด PowerShell ในโฟลเดอร์โปรเจกต์แล้วรัน

```powershell
npm.cmd ci
npm.cmd run dev
```

เปิด [หน้าแรก](http://localhost:3000) แล้วเลือก **ประเมินราคา** หรือไปที่ [หน้าประเมินราคา](http://localhost:3000/estimate) โดยตรง

## ส่งต่องานให้ทีม

- ใช้ `.env.example` เป็นรายการตัวแปรและเก็บค่าจริงไว้ใน `.env.local` หรือ Environment Variables ของ Vercel สำหรับทดสอบงานที่เขียนข้อมูล ให้ใช้ SQLite ในเครื่องหรือฐานข้อมูลทดสอบของทีม
- โปรเจกต์จริงอยู่ที่ `p3d-web` บน Vercel ใช้ Turso สำหรับฐานข้อมูล และใช้ Google Cloud กับ LINE Developers สำหรับการเข้าสู่ระบบ ผู้ดูแลบริการเดิมสามารถเพิ่มสิทธิ์ให้สมาชิกทีมในแต่ละระบบได้ตามหน้าที่
- `app/` มีหน้าเว็บลูกค้า ตัวประเมินราคา และหน้าหลังบ้าน ส่วน `lib/account-store.js` จัดการฐานข้อมูล `lib/line-notify.js` ส่งข้อความให้ลูกค้า และ `lib/order-notifications.js` แจ้งออเดอร์ใหม่ให้ร้าน สินทรัพย์ที่เว็บใช้เก็บใน `public/`

## เปิดใช้ Google และ LINE Login

1. คัดลอก `.env.example` เป็น `.env.local` แล้วสร้างค่า `AUTH_SECRET` ตามคำสั่งตัวอย่างในไฟล์
2. สร้าง OAuth client ประเภท Web application ใน Google Cloud และ LINE Login channel ที่เปิดใช้ Web app ใน LINE Developers
3. กรอก Client ID และ Client Secret ของ Google กับ Channel ID และ Channel Secret ของ LINE ใน `.env.local` หรือ Environment Variables ของโฮสต์
4. ตั้ง `AUTH_URL` ให้ตรงกับ URL ที่ผู้ใช้เปิด แล้วลงทะเบียน callback ของแต่ละบริการตามตาราง
5. รีสตาร์ตเว็บแล้วลองเข้าสู่ระบบทีละช่องทาง หาก LINE channel ยังอยู่ในสถานะ Developing ให้ใช้บัญชีที่มีสิทธิ์ทดสอบ

| บริการ | Callback สำหรับพัฒนา | Callback บนโฮสต์ |
| --- | --- | --- |
| Google | `http://localhost:3000/api/auth/callback/google` | `https://YOUR-DOMAIN/api/auth/callback/google` |
| LINE ช่องเดิม | `http://localhost:3000/api/auth/callback/line` | `https://YOUR-DOMAIN/api/auth/callback/line` |
| LINE ช่องที่ผูกกับ OA | `http://localhost:3000/api/auth/callback/line-oa` | `https://YOUR-DOMAIN/api/auth/callback/line-oa` |

ช่อง LINE ที่ใช้งานร่วมกับ OA ต้องอยู่ใน LINE Provider เดียวกับ Messaging API ของร้าน ตั้งค่าด้วย `P3D_LINE_OA_ID` และ `P3D_LINE_OA_SECRET` ส่วน `AUTH_LINE_ID` และ `AUTH_LINE_SECRET` ใช้สำหรับเข้าบัญชีเดิมและผูก LINE ใหม่กับออเดอร์เดิม

หาก LINE ไม่รับ URL บนเครื่อง ให้ใช้โดเมนทดสอบ HTTPS และตั้ง `AUTH_URL` ให้ตรงกัน ระบบขอชื่อโปรไฟล์จาก LINE โดยใช้ scope `openid profile`

## บัญชีลูกค้า

หน้า `/account` ใช้จัดการข้อมูลติดต่อและที่อยู่จัดส่ง บัญชีและโปรไฟล์จะถูกสร้างเมื่อเข้าสู่ระบบครั้งแรก ผู้ที่ล็อกอินก่อนเพิ่มหน้าบัญชีอาจต้องเข้าสู่ระบบใหม่หนึ่งครั้ง

ในเครื่อง ระบบใช้ SQLite ที่ `.p3d-data/accounts.sqlite` ตั้ง `P3D_ACCOUNT_DATA_DIR` เพื่อเลือกไดเรกทอรีอื่นได้ บน Vercel ตั้ง `TURSO_DATABASE_URL` และ `TURSO_AUTH_TOKEN` เพื่อใช้ Turso ฐานข้อมูลอยู่ฝั่งเซิร์ฟเวอร์และเข้าถึงข้อมูลตามบัญชีที่เข้าสู่ระบบ

## คำสั่งพิมพ์และชำระเงิน

จัดการวัสดุ สี และจำนวนกรัมที่ `/admin/stock` หน้าประเมินราคาอ่านรายการที่มีสต๊อก และตรวจซ้ำตอนส่งออเดอร์ ลูกค้าแนบสลิป PromptPay ที่หน้าออเดอร์ หลังบ้านเปิดดูสลิปและยืนยันยอดได้

เลือกไฟล์จริงในหน้า `/estimate` แล้วกด **สั่งพิมพ์** เลือกไปรษณีย์ 45 บาท หรือ LALAMOVE ซึ่งจ่ายค่าจัดส่งปลายทางแยกจากยอด PromptPay ระบบบันทึกค่าพิมพ์ ที่อยู่จัดส่ง ณ เวลาสั่ง และไฟล์ STL ตามแนววางลง SQLite ลูกค้าเปิดคำสั่งเดิมและ QR ได้จากหน้าบัญชี

## เว็บหลังบ้านแอดมิน

รัน `npm.cmd run build` ก่อน จากนั้นเปิดเว็บลูกค้าด้วย `npm.cmd run start` และเปิดหลังบ้านอีกหน้าต่างด้วย `npm.cmd run start:admin` ที่ [http://localhost:3001](http://localhost:3001) ทั้งสองเว็บใช้ SQLite เดียวกัน ถ้าเปลี่ยนที่เก็บ ให้ตั้ง `P3D_ACCOUNT_DATA_DIR` ให้ตรงกันทั้งสองโปรเซส

ตั้ง `P3D_ADMIN_EMAILS` เป็นอีเมล Google ของแอดมิน คั่นด้วยจุลภาคถ้ามีหลายคน แล้วเพิ่ม `http://localhost:3001/api/auth/callback/google` ใน **Authorized redirect URIs** ของ OAuth Client ตัวเดิม โดยเก็บ Callback ของเว็บลูกค้าที่พอร์ต 3000 ไว้ด้วย หากใช้โดเมนจริง ให้ตั้ง `P3D_CUSTOMER_URL` และ `P3D_ADMIN_URL` ให้ตรงกับโดเมนของแต่ละเว็บ

ลูกค้าสแกน QR PromptPay ของร้าน แอดมินตรวจยอดแล้วกด **ยืนยันว่าได้รับเงินแล้ว** จากนั้นเลือกสถานะงานและใส่บริษัทขนส่งกับเลขติดตาม ลูกค้าดูความคืบหน้าที่ `/orders` ของเว็บลูกค้า

## แจ้งเตือนคำสั่งพิมพ์ใหม่ใน LINE

เปิด [LINE Messaging API](https://developers.line.biz/en/docs/messaging-api/getting-started/) ของ LINE Official Account แล้วตั้ง `LINE_MESSAGING_CHANNEL_ACCESS_TOKEN` กับ `LINE_ADMIN_RECIPIENT_ID` ฝั่งเว็บลูกค้า ใช้ user ID ของแอดมินที่เพิ่ม OA เป็นเพื่อน หรือ group ID ของห้องที่เชิญ OA เข้ามา หากใช้เว็บแอดมินแยกโดเมน ให้ตั้ง `P3D_ADMIN_URL` ให้ตรงกับเว็บหลังบ้าน

เมื่อบันทึกคำสั่งพิมพ์สำเร็จ เว็บส่งเลขออเดอร์ ยอดตามคำสั่งซื้อ และลิงก์หลังบ้านเข้า LINE โดยไม่ส่งข้อมูลส่วนตัวของลูกค้า หาก LINE ตอบชั่วคราวผิดพลาด ระบบลองส่งซ้ำด้วยรหัสออเดอร์เดิมเพื่อกันข้อความซ้ำ

## ตั้งราคาของร้าน

แก้ `app/pricing.js` เพื่อกำหนดราคาวัสดุต่อกรัม ค่าเครื่องต่อชั่วโมง สัดส่วนค่าแรง ค่าดำเนินการ และค่าจัดส่ง ขนาดพิมพ์สูงสุด 255 × 255 × 255 มม. ในแนววางของไฟล์

สูตรอ้างอิงผลจากตัวประเมิน P3D เดิม โดยใช้ปริมาตรโมเดล จำนวนผนัง และ Infill ประเมินปริมาณวัสดุ แล้วใช้ความสูงชั้นพิมพ์ ชนิดวัสดุ และซัพพอร์ตประเมินเวลา ค่าแรงคิดจากค่าวัสดุ และค่าดำเนินการกับค่าส่งคิดครั้งเดียวต่อการประเมิน ระบบปัดราคาแต่ละรายการและราคารวมแยกกัน ราคาจริงขึ้นกับผลจากโปรแกรม Slicer

รองรับ STL และ OBJ ที่ใช้มิลลิเมตร รวมถึง 3MF ที่ใช้หน่วยเดียวกันทั้งไฟล์ รับโมเดลครั้งละหนึ่งไฟล์ไม่เกิน 20 MB และ 240,000 สามเหลี่ยม ควรส่งออกโมเดลที่ผิวปิดสนิทเพื่อให้คำนวณปริมาตรได้ ไฟล์อยู่ในเบราว์เซอร์ระหว่างประเมิน

## จัดวางบนแผ่นพิมพ์

ตัวดูโมเดลแสดงแผ่นพิมพ์ 255 × 255 มม. ตามสเกลจริง หมุนชิ้นงานรอบแกน X, Y หรือ Z แล้วระบบวัดขนาดตามแนวใหม่และวางให้แตะแผ่น ใช้คลิกซ้ายค้างแล้วลากเพื่อหมุนกล้อง คลิกขวาค้างแล้วลากเพื่อเลื่อนมุมมอง และล้อเมาส์เพื่อซูม กด R เพื่อเปิดวงแหวนหมุนชิ้นงานหรือกรอกองศาตามแกนแผ่นพิมพ์

**วางราบอัตโนมัติ** เลือกด้านราบที่สัมผัสแผ่นได้จากพื้นที่ผิวของโมเดล หรือใช้ **วางตามผิว (F)** แล้วคลิกหรือแตะด้านที่ต้องการ กด Esc เพื่อยกเลิกโหมดเลือกผิว **Arrange** จัดสำเนาของโมเดลเดียวตามจำนวนชิ้น เว้นระยะ 5 มม. และแบ่งแผ่นเมื่อวางไม่พอ

**Overhang** ใช้สีส้มแสดงผิวที่หันลงตั้งแต่ 45° จากแนวดิ่งและอยู่เหนือแผ่น เป็นการตรวจจากรูปทรง จึงอาจรวมสะพานหรือบริเวณที่ Slicer จะใช้การตั้งค่าต่างกัน ปุ่ม Overhang ใช้ดูผิวได้โดยอิสระ เมื่อเปิด Support ระบบแสดงกิ่ง Tree Organic สีเขียวโดยประมาณจากแผ่นพิมพ์และรวมเวลาเพิ่มตามสูตรประเมินเดิม การสร้างซัพพอร์ตเพื่อพิมพ์จริงขึ้นกับ Slicer
